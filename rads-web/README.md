# RADS Web

> AI notice: All of this browser port was generated by AI.

RADS Web pulls the RADS file from archive.org with range headers.

## Files

- `index.html` - the browser UI.
- `rman.js` - a single-file browser RMAN manifest parser and downloader helper.
